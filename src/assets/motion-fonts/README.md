# Motion graphic fonts

Bundled so motion graphics look the same on every machine and in every export.
All are licensed under the SIL Open Font License 1.1 (https://openfontlicense.org),
downloaded from Google Fonts:

- Inter (400, 600, 800) — Rasmus Andersson
- DM Sans (400, 500, 700; static cuts of the variable font at 14 pt) — Colophon Foundry, Cue's interface font
- Space Grotesk (500, 700) — Florian Karsten
- Instrument Serif (400) — Instrument
- JetBrains Mono (500) — JetBrains
